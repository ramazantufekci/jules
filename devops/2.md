# 📅 DevOps Öğrenme Planı

## 🔹 **Ay 1–2: Temeller**

✅ Hedef: Linux, Git, temel programlama ve ağ bilgisini öğrenmek.

* Linux terminal komutlarını öğren (ls, cd, grep, ps, top, chmod, chown).
* Bash scripting ile basit otomasyon scriptleri yaz.
* Git ve GitHub/GitLab kullanarak repo oluştur, branch aç, PR yap.
* Python temellerini öğren (dosya işlemleri, HTTP request, basit API entegrasyonu).
* Networking: TCP/IP, HTTP, DNS, SSH temellerini kavra.

**Mini Proje:** Basit bir Python uygulaması yaz (örn: hava durumu API’si), Linux üzerinde çalıştır, GitHub’a yükle.

---

## 🔹 **Ay 3–4: Konteyner & CI/CD Temeli**

✅ Hedef: Docker ve basit CI/CD pipeline öğrenmek.

* Docker:

  * Dockerfile yazmayı öğren.
  * Docker Compose ile çoklu servis yönet.
* CI/CD:

  * GitHub Actions veya GitLab CI/CD ile pipeline kur.
  * Her commit’te otomatik build ve test çalıştır.

**Mini Proje:** Flask/Django veya Node.js uygulamasını Dockerize et, GitHub Actions ile otomatik build edip test et.

---

## 🔹 **Ay 5–6: Kubernetes & Infrastructure as Code**

✅ Hedef: Orkestrasyon ve altyapı yönetimi öğrenmek.

* Kubernetes (K8s):

  * Pod, Deployment, Service, Ingress kavramları.
  * ConfigMap & Secret yönetimi.
  * Minikube veya Kind ile lokal cluster kur.
* Infrastructure as Code:

  * Terraform temelleri.
  * AWS EC2 veya DigitalOcean üzerinde VM oluşturmayı öğren.

**Mini Proje:** Dockerized uygulamanı Kubernetes’e deploy et. Terraform ile altyapını otomatik oluştur.

---

## 🔹 **Ay 7–8: Cloud Platformları**

✅ Hedef: Bulut servislerine giriş.

* AWS / Azure / GCP’den birini seç (AWS öneririm).
* EC2, S3, RDS, IAM, VPC temellerini öğren.
* Cloud üzerinde Kubernetes cluster (EKS/GKE/AKS) kurmayı dene.

**Mini Proje:** Web uygulamanı AWS üzerinde çalıştır → S3 ile statik dosyaları depola → RDS ile veritabanı bağla.

---

## 🔹 **Ay 9–10: İzleme & Loglama**

✅ Hedef: Monitoring ve log yönetimi.

* Prometheus + Grafana ile metrik toplama.
* ELK Stack (Elasticsearch, Logstash, Kibana) veya Loki + Grafana ile log analizi.
* Alertmanager ile alarmlar tanımla.

**Mini Proje:** Kubernetes üzerinde çalışan uygulaman için Prometheus + Grafana monitoring dashboard kur.

---

## 🔹 **Ay 11–12: İleri Seviye & Gerçek Hayat Senaryoları**

✅ Hedef: DevOps kültürü ve ileri konular.

* CI/CD’yi daha güvenli hale getir (kod tarama, dependency scanning).
* Secrets yönetimi (HashiCorp Vault, K8s Secrets).
* Blue/Green Deployment, Canary Deployment öğren.
* SRE (Site Reliability Engineering) prensiplerine göz at.

**Mini Proje (Bitirme):**

* Uygulamanı Kubernetes + Terraform + AWS üzerinde kur.
* CI/CD pipeline → her commit’te otomatik build & deploy.
* Monitoring & alert sistemi kur.

---

# 🎯 Özet Yol Haritası

1. **Ay 1–2:** Linux, Git, Python, Networking
2. **Ay 3–4:** Docker, CI/CD
3. **Ay 5–6:** Kubernetes, Terraform
4. **Ay 7–8:** Cloud (AWS)
5. **Ay 9–10:** Monitoring & Logging
6. **Ay 11–12:** Security, Deployment stratejileri, SRE
