# 🐚 **Bash Scripting Temelleri**

## 1. Değişkenler

```bash
#!/bin/bash

# Değişken tanımlama
isim="Ahmet"
yas=25

# Kullanma
echo "Merhaba, benim adım $isim ve $yas yaşındayım."
```

---

## 2. Koşullar (if-else)

```bash
#!/bin/bash

sayi=10

if [ $sayi -gt 5 ]; then
    echo "Sayı 5'ten büyük"
else
    echo "Sayı 5 veya daha küçük"
fi
```

---

## 3. Döngüler

**For Döngüsü**

```bash
#!/bin/bash

for i in {1..5}
do
   echo "Adım: $i"
done
```

**While Döngüsü**

```bash
#!/bin/bash

sayi=1
while [ $sayi -le 3 ]
do
   echo "Sayı: $sayi"
   sayi=$((sayi+1))
done
```

---

## 4. Parametre Kullanımı

```bash
#!/bin/bash

echo "1. Parametre: $1"
echo "2. Parametre: $2"
```

Çalıştırma:

```bash
bash script.sh Ahmet 25
```

# ⏰ **Cronjob ile Otomasyon**

**Cronjob** → Belirli zamanlarda komut/script çalıştırmaya yarar.

## 1. Cronjob Listeleme

```bash
crontab -l
```

## 2. Cronjob Düzenleme

```bash
crontab -e
```

## 3. Zaman Formatı

```
* * * * *  komut
│ │ │ │ │
│ │ │ │ └─ Haftanın günü (0-6, Pazar=0)
│ │ │ └─── Ay (1-12)
│ │ └───── Gün (1-31)
│ └─────── Saat (0-23)
└───────── Dakika (0-59)
```

## 4. Örnek Cronjoblar

* Her gün saat 03:00’da çalıştır:

```bash
0 3 * * * /home/kullanici/backup.sh
```

* Her 5 dakikada bir çalıştır:

```bash
*/5 * * * * /home/kullanici/healthcheck.sh
```

* Her pazartesi 09:00’da çalıştır:

```bash
0 9 * * 1 /home/kullanici/report.sh
```

# 🎯 Mini Proje Önerisi

1. Bir `backup.sh` scripti yaz → `/var/log` dizinindeki logları `tar.gz` yapıp `/home/kullanici/backup/` dizinine koysun.
2. Bu scripti cronjob’a ekle → her gece 02:00’de otomatik çalışsın.
