Harika! 🚀 O zaman sana gerçek hayatta işine yarayacak bir **backup.sh scripti** ve onu cronjob’a nasıl ekleyeceğini adım adım göstereyim.

---

# 📂 **1. Backup Script (backup.sh)**

```bash
#!/bin/bash
# ==========================
# Log klasörlerini yedekleme scripti
# ==========================

# Tarih formatı (YYYY-MM-DD)
DATE=$(date +%F)

# Kaynak klasör (yedeklenecek)
SOURCE="/var/log"

# Hedef klasör (yedeklerin saklanacağı)
DEST="/home/kullanici/backup"

# Eğer hedef klasör yoksa oluştur
mkdir -p $DEST

# Yedek dosyasını oluştur
tar -czf $DEST/logs_backup_$DATE.tar.gz $SOURCE

# Eski yedekleri 7 günden sonra sil
find $DEST -type f -name "*.tar.gz" -mtime +7 -exec rm {} \;

echo "[$(date)] Backup işlemi tamamlandı: $DEST/logs_backup_$DATE.tar.gz"
```

---

# ⚙️ **2. Çalıştırma İzinleri**

Script’e çalıştırma izni ver:

```bash
chmod +x backup.sh
```

Test et:

```bash
./backup.sh
```

---

# ⏰ **3. Cronjob ile Otomatik Çalıştırma**

Cronjob dosyasını aç:

```bash
crontab -e
```

Her gece **02:00’de çalışması** için satırı ekle:

```bash
0 2 * * * /home/kullanici/backup.sh >> /home/kullanici/backup/backup.log 2>&1
```

📌 Açıklama:

* `0 2 * * *` → her gün saat 02:00’de çalışır
* `>> backup.log 2>&1` → çıktı ve hataları log dosyasına yazar

---

# 🎯 Ne Kazandırır?

* `/var/log` klasöründeki logların **günlük yedeği** alınır
* Yedekler `tar.gz` olarak saklanır
* 7 günden eski yedekler otomatik silinir → disk şişmez
* Çalışma logu `backup.log` içine kaydedilir
