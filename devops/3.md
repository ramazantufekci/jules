# 📅 Haftalık DevOps Çalışma Programı (12 Ay)

---

## 🔹 **Ay 1–2: Temeller (Linux, Git, Python, Networking)**

**Hafta 1–2**

* Linux dosya sistemi, temel komutlar (`ls`, `cd`, `cat`, `grep`, `find`)
* Kullanıcı/izin yönetimi (`chmod`, `chown`)
* SSH ile uzak sunucuya bağlanma

**Hafta 3–4**

* Bash scripting (değişkenler, döngüler, koşullar)
* Cronjob ile otomasyon

**Hafta 5–6**

* Git temel komutlar (`clone`, `commit`, `push`, `pull`)
* Branching ve merge mantığı
* GitHub/GitLab kullanımı

**Hafta 7–8**

* Python temelleri (fonksiyon, modül, paket)
* Basit API isteği yap (requests kütüphanesi)
* Networking: TCP/IP, HTTP, DNS temelleri

**🎯 Mini Proje:**
Küçük bir Python scripti yaz → GitHub’a yükle → Linux üzerinde cronjob ile otomatik çalıştır.

---

## 🔹 **Ay 3–4: Konteyner & CI/CD Temeli**

**Hafta 9–10**

* Docker temelleri: Image, Container, Volume
* Dockerfile yazma ve image oluşturma
* DockerHub’a image push etme

**Hafta 11–12**

* Docker Compose ile çoklu servis çalıştırma (örn: web + database)
* Port, environment variable yönetimi

**Hafta 13–14**

* CI/CD mantığı → Build, Test, Deploy adımları
* GitHub Actions ile basit bir pipeline kur (build + test)

**Hafta 15–16**

* GitLab CI/CD öğren
* Pipeline dosyası (`.gitlab-ci.yml`) yaz
* Pipeline’dan Docker image build edip deploy et

**🎯 Mini Proje:**
Flask veya Node.js uygulamasını Dockerize et → GitHub Actions ile otomatik build/test çalıştır.

---

## 🔹 **Ay 5–6: Kubernetes & Infrastructure as Code**

**Hafta 17–18**

* Kubernetes temelleri: Pod, Deployment, Service
* Minikube veya Kind ile lokal cluster kur

**Hafta 19–20**

* ConfigMap & Secret yönetimi
* Ingress ile dış dünyaya açılma
* Kubectl komutları öğren (`get pods`, `logs`, `describe`)

**Hafta 21–22**

* Terraform temeli (provider, resource, variable)
* AWS/DigitalOcean üzerinde basit bir VM oluştur

**Hafta 23–24**

* Terraform ile Kubernetes cluster oluşturma
* Terraform state mantığını öğren

**🎯 Mini Proje:**
Dockerize uygulamanı Kubernetes’e deploy et → Terraform ile altyapıyı otomatik oluştur.

---

## 🔹 **Ay 7–8: Cloud (AWS / Azure / GCP)**

**Hafta 25–26**

* AWS giriş: IAM (kullanıcı & rol), EC2, S3
* CLI kullanarak kaynak oluşturma

**Hafta 27–28**

* VPC (ağ yönetimi), güvenlik grupları
* Load balancer mantığı

**Hafta 29–30**

* RDS ile veritabanı oluştur
* EC2 + RDS entegrasyonu

**Hafta 31–32**

* EKS (Kubernetes on AWS) temeli
* Terraform ile AWS kaynakları yönet

**🎯 Mini Proje:**
Web uygulamanı AWS üzerinde çalıştır (EC2 + RDS + S3) → Terraform ile otomatikleştir.

---

## 🔹 **Ay 9–10: Monitoring & Logging**

**Hafta 33–34**

* Prometheus kurulumu
* Metric toplama (CPU, bellek, request sayısı)

**Hafta 35–36**

* Grafana kurulumu
* Dashboard oluşturma

**Hafta 37–38**

* ELK (Elasticsearch, Logstash, Kibana) kurulumu
* Basit log analizi yap

**Hafta 39–40**

* Loki + Grafana log management
* Alertmanager ile alarmlar

**🎯 Mini Proje:**
Kubernetes cluster’ında çalışan uygulaman için Prometheus + Grafana monitoring dashboard kur.

---

## 🔹 **Ay 11–12: İleri Seviye & Bitirme Projesi**

**Hafta 41–42**

* Deployment stratejileri: Blue/Green, Canary
* Helm Chart kullanımı

**Hafta 43–44**

* Secrets yönetimi (HashiCorp Vault, K8s Secrets)
* CI/CD pipeline’da güvenlik taraması ekleme

**Hafta 45–46**

* SRE prensipleri (SLI, SLO, SLA)
* Chaos engineering kavramı

**Hafta 47–48**

* Tüm öğrendiklerini birleştir → bitirme projesi yap

**🎯 Bitirme Projesi:**

* Dockerize uygulama → Kubernetes (EKS) üzerinde çalışıyor
* Terraform ile tüm altyapı kuruluyor
* CI/CD pipeline (GitHub Actions / GitLab CI) otomatik build & deploy yapıyor
* Prometheus + Grafana monitoring mevcut
* Secrets güvenli şekilde yönetiliyor

---
